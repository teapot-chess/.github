# The stars of Sagittarius

Software for running chess tournaments, from the first pairing to the last
printed result. Every program is named after a star in Sagittarius; a few of
them sit in the Teapot, which is where the name of this organization comes
from. Nobody asked the stars.

| | Program | What it does |
|---|---|---|
| <img src="marks/openpairings.svg" width="32" alt=""> | **[OpenPairings](https://github.com/teapot-chess/openpairings)** | The tournament manager: players, pairings, results, standings, FIDE rating reports. Runs on your PC or at [pairings.cloud](https://pairings.cloud). |
| <img src="marks/ainalrami.svg" width="32" alt=""> | **[Ainalrami](https://github.com/teapot-chess/Ainalrami)** | The pairing engine underneath: the FIDE Dutch system (with Baku acceleration) and team Swiss, checked against hundreds of millions of reference pairings. |
| | **[OpenResults](https://github.com/teapot-chess/openresults)** | The public results site: pairings, standings and crosstables for spectators, at [openresults.cloud](https://openresults.cloud). |
| <img src="marks/alnasl.svg" width="32" alt=""> | **[Alnasl](https://github.com/teapot-chess/Alnasl)** | Live boards: collects the moves from the electronic boards in the hall and shows them to the world. |
| <img src="marks/arkab.svg" width="32" alt=""> | **[Arkab](https://github.com/teapot-chess/Arkab)** | The hall bridge: reads the boards on site and sends them to Alnasl. |
| <img src="marks/polis.svg" width="32" alt=""> | **[Polis](https://github.com/teapot-chess/Polis)** | The print station: pairings and place cards come out of the hall printer the moment a round is published. |
| <img src="marks/nunki.svg" width="32" alt=""> | **[Nunki](https://github.com/teapot-chess/Nunki)** | The hall announcer: round countdown, and the pairings read aloud. |
| <img src="marks/ascella.svg" width="32" alt=""> | **[Ascella](https://github.com/teapot-chess/Ascella)** | Installs, updates, starts and stops all of the above on one machine, so the arbiter doesn't have to. |

Windows, macOS (Apple Silicon) and Linux builds are on each program's
Releases page.
